# کارگاه طراحی سایت با هوش مصنوعی — نسخه ۲ (عملی)

یک **فایل تک و خودکفا**: `index.html`. هیچ نصبی، هیچ وابستگی‌ای، هیچ اینترنتی لازم نیست.
با دابل‌کلیک در مرورگر باز می‌شود.

## تفاوت با نسخه ۱

| نسخه ۱ | نسخه ۲ |
|---|---|
| مفاهیم توضیح داده می‌شد | هر مفهوم **همان لحظه روی صفحه اجرا می‌شود** |
| کد به‌صورت متن | کد + **پیش‌نمایش زنده** کنار هم |
| SQL در حد یک نمونه | **۹ اسلاید** دیتابیس: CREATE، INSERT، SELECT تعاملی، UPDATE/DELETE، JOIN، PHP، SQL Injection |
| فایل‌ها در ریپو | **دکمه دانلود zip داخل خود صفحه** |
| اسلاید ثابت | **زمین بازی کد** برای تمرین زنده شرکت‌کنندگان |

## کلیدهای میان‌بر

| کلید | کار |
|---|---|
| `←` / `Space` | اسلاید بعدی |
| `→` | اسلاید قبلی |
| `N` | یادداشت مدرس (متن پیشنهادی گفتار) |
| `G` | پلن اجرا — چک‌لیست، زمان‌بندی، نقشه اضطراری |
| `D` | بسته‌ی فایل‌های آماده |
| `T` | تایمر با نشانگر عقب/جلو بودن از برنامه |
| `M` | فهرست · `F` تمام‌صفحه |

## بسته‌ی کدها

دکمه 📦 بالای صفحه → «دانلود همه (zip)». فایل zip شامل یک پروژه‌ی کامل و کارکننده است:

```
index.html   صفحه اصلی (راست‌چین، ریسپانسیو)
style.css    استایل‌ها
script.js    منوی موبایل، اسکرول نرم، انیمیشن
config.php   اتصال دیتابیس (۴ خط اول را روی هاست عوض کنید)
contact.php  ذخیره امن فرم با PDO + Prepared Statement
inbox.php    نمایش پیام‌ها از دیتابیس
database.sql ساخت جدول‌ها + داده نمونه برای تمرین SQL
prompts.txt  همه‌ی پرامپت‌های کارگاه
README.txt   راهنمای راه‌اندازی
```

راه‌اندازی: محتویات zip را در `C:\xampp\htdocs\mysite` بریزید،
در phpMyAdmin فایل `database.sql` را import کنید، و `http://localhost/mysite` را باز کنید.

نسخه ۱ در پوشه‌ی `workshop/` باقی مانده است.
