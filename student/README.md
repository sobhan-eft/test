# نسخه‌ی دانشجویان — برای آپلود

دو فایل، هر دو مستقل و بدون وابستگی. هرجا آپلودشان کنید کار می‌کنند.

| فایل | برای چه |
|---|---|
| `index.html` | **راهنمای اصلی.** صفحه‌ی اسکرولی با فهرست، جست‌وجو، پیشرفت قابل تیک زدن و جمع‌بندی درختی. لینکی که به بچه‌ها می‌دهید همین است. |
| `slides.html` | همان اسلایدهای کارگاه، بدون یادداشت مدرس. برای مرور بعد از جلسه. |

دو فایل به هم لینک دارند، پس کافی است هر دو را کنار هم بگذارید.

## آپلود

**روی هاست خودتان:** هر دو فایل را در `public_html` بریزید. لینک: `https://yoursite.ir/index.html`

**رایگان:** پوشه را در [netlify.com](https://netlify.com) drag & drop کنید، یا در یک مخزن GitHub بگذارید و
Settings ← Pages را فعال کنید.

## داخل `index.html` چه چیزی هست

- پیش‌نمایش زنده کنار هر قطعه کد (HTML، CSS، خروجی PHP)
- زمین بازی برای نوشتن کد و دیدن نتیجه‌ی فوری
- کاوشگر SQL با هشت کوئری آماده روی داده‌ی نمونه
- همه‌ی پرامپت‌ها با دکمه‌ی کپی
- دکمه‌ی 📦 که کل پروژه را به صورت zip روی سیستم کاربر می‌سازد
  (`index.html`، `style.css`، `script.js`، `config.php`، `contact.php`، `inbox.php`،
  `database.sql`، `prompts.txt`، `README.txt`)
- تم روشن/تیره، جست‌وجو، و پیشرفت که در مرورگر خود کاربر ذخیره می‌شود
- جمع‌بندی درختی در انتها: «از اینجا به بعد چه کار کنم»

هیچ داده‌ای جایی ارسال نمی‌شود؛ پیشرفت و کد زمین بازی فقط در مرورگر خود کاربر می‌ماند.
