XAMPP

C:\xampp\htdocs\mysite\index.html → http://localhost/mysite public_html/index.html → https://yoursite.ir
Apache روشن نمی‌شود — Port 80 in use
  1. XAMPP ← روبه‌روی Apache دکمه Config ← httpd.conf
  2. Listen 80 را به Listen 8080 تغییر دهید
  3. ServerName localhost:80 را به localhost:8080 تغییر دهید
  4. ذخیره، Start دوباره. آدرس جدید: http://localhost:8080/mysite
MySQL روشن نمی‌شود

یک نسخه‌ی دیگر MySQL پورت ۳۳۰۶ را گرفته. در ویندوز Services را باز کنید، سرویس MySQL را متوقف کنید، دوباره Start بزنید.

prompt-04-project
تو یک برنامه‌نویس وب حرفه‌ای هستی که با PHP و MySQL سایت‌های فارسی و راست‌چین می‌سازی.

یک سایت سه‌صفحه‌ای «مقالات و یادداشت‌های علمی» بساز که به دیتابیس وصل است.

━━ دیتابیس ━━
فایل schema.sql با سه جدول (utf8mb4 و utf8mb4_persian_ci):

categories : id, name
articles   : id, title, excerpt, body, category_id (کلید خارجی به categories),
             author, views (پیش‌فرض ۰), is_published (۰ یا ۱), created_at
comments   : id, article_id (کلید خارجی), name, email, body,
             is_approved (پیش‌فرض ۰), created_at

در همان فایل، ۳ دسته و ۶ مقاله‌ی نمونه‌ی فارسی هم INSERT کن.

━━ صفحه ۱ — index.php : لیست مقالات ━━
• فقط مقالاتی که is_published = 1
• نام دسته را با JOIN از جدول categories بیاور
• جست‌وجو در عنوان و متن با پارامتر ?q=
• فیلتر بر اساس دسته با پارامتر ?cat=
• صفحه‌بندی ۶ تایی با LIMIT و OFFSET و شماره‌ی صفحه‌ها در پایین
• هر مقاله یک کارت: عنوان، نام دسته، خلاصه، تعداد بازدید، تاریخ

━━ صفحه ۲ — article.php?id=... : یک مقاله ━━
• اگر id نامعتبر بود یا مقاله منتشر نشده بود، پیام ۴۰۴ فارسی نشان بده
• با هر بازدید، ستون views را یکی زیاد کن
• «مقالات مرتبط»: سه مقاله‌ی دیگر از همان دسته
• پایین صفحه فرم نظر (نام، ایمیل، متن) که در جدول comments با is_approved = 0 ذخیره شود
• فقط نظرهای تأییدشده زیر مقاله نمایش داده شوند

━━ صفحه ۳ — admin.php : پنل مدیریت ━━
• ورود با رمزی که در config.php ذخیره شده و با password_verify چک می‌شود؛ وضعیت ورود در session
• جدول همه‌ی مقالات با دکمه‌های افزودن، ویرایش و حذف (حذف با تأیید گرفتن)
• فرم افزودن/ویرایش مقاله با انتخاب دسته و وضعیت انتشار
• بخش تأیید نظرها: لیست نظرهای در انتظار با دکمه‌ی تأیید و حذف
• دکمه‌ی خروج

۱. ساخت جدول

database.sql
CREATE DATABASE IF NOT EXISTS mysite_db
  DEFAULT CHARACTER SET utf8mb4
  COLLATE utf8mb4_persian_ci;

USE mysite_db;

CREATE TABLE IF NOT EXISTS messages (
  id         INT AUTO_INCREMENT PRIMARY KEY,
  name       VARCHAR(100) NOT NULL,
  email      VARCHAR(150) NOT NULL,
  subject    VARCHAR(200) NOT NULL,
  message    TEXT         NOT NULL,

اتصال PHP به دیتابیس

config.php
<?php
// روی هاست فقط این ۴ خط عوض می‌شود
define('DB_HOST', 'localhost');
define('DB_NAME', 'mysite_db');
define('DB_USER', 'root');
define('DB_PASS', '');

function db() {
    static $pdo = null;
    if ($pdo === null) {
        $dsn = 'mysql:host='.DB_HOST
              .';dbname='.DB_NAME
              .';charset=utf8mb4';
        $pdo = new PDO($dsn, DB_USER, DB_PASS, [
            PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
            PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
            PDO::ATTR_EMULATE_PREPARES => false,
        ]);
    }
    return $pdo;
}

        [$name, $email, $subject, $message]
    );
    echo 'پیام شما ثبت شد';
}

امنیت

✕ آسیب‌پذیر
$sql = "SELECT * FROM users
        WHERE user = '$user'
          AND pass = '$pass'";
db()->query($sql);
✓ امن
$sql  = 'SELECT * FROM users
         WHERE user = ? AND pass = ?';
$stmt = db()->prepare($sql);
$stmt->execute([$user, $pass]);
اگر کاربر در فیلد رمز این را بنویسد
' OR '1'='1
در کد آسیب‌پذیر این دستور اجرا می‌شود
SELECT * FROM users WHERE user = 'admin' AND pass = '' OR '1'='1'
نتیجهورود بدون دانستن رمز
  • در پرامپت بنویسید: «از PDO با Prepared Statement استفاده کن، ورودی‌ها را با filter_var اعتبارسنجی کن، خروجی را با htmlspecialchars پاک‌سازی کن.»
  • رمز عبور را با password_hash() ذخیره کنید، نه متن ساده.
  • روی هاست، نمایش خطاها را خاموش کنید.

  1. لینک گالری را باز کنید و «ارسال کار من» را بزنید.
  2. مشخصات و کد index.html خود را بگذارید (یا فایلش را انتخاب کنید).
  3. پیش‌نمایش را همان‌جا ببینید و بفرستید.
  4. لینک ویرایشی که می‌گیرید را نگه دارید تا بعداً بتوانید کارتان را به‌روز کنید.

باز کردن گالری کارگاه ↗

سایتتان چند فایل است؟ از هوش مصنوعی بخواهید همه را یکی کند: «تمام CSS و JavaScript را داخل همین فایل HTML بگذار و یک فایل واحد بده». یا اگر سایت را منتشر کرده‌اید، فقط آدرسش را بدهید.

🌳 از اینجا به بعد چه کار کنم

کل مسیر در یک نگاه. از بالا شروع کنید و هر شاخه‌ای که به شما مربوط است را دنبال کنید.

  • ۱چه نوع سایتی می‌خواهم؟
    • فقط معرفی و رزومه بدون فرم و دیتابیس
      • Aپرامپت ۱ را بفرست ← کد را در index.html ذخیره کن
      • Bبا مرورگر بازش کن و اصلاحش کن (پرامپت ۲)
      • ✅ روی GitHub Pages یا Netlify منتشر کن — تمام
        • نه XAMPP لازم است، نه هاست، نه هزینه
    • فرم تماس و دیتابیس می‌خواهم
      • مسیر کامل را از قدم ۲ ادامه بده ↓
  • ۲محیط کار را آماده کن
    • XAMPP را نصب کن
    • Apache و MySQL را Start کن هر دو سبز
    • فایل‌های بسته را در htdocs\mysite بریز
    • http://localhost/mysite باید باز شود
      • باز نشد؟ ← بخش XAMPP، قسمت «Port 80 in use»
  • ۳ظاهر سایت را بساز
    • پرامپت ۱ ← کد بگیر ← در index.html ذخیره کن
      • Notepad: Encoding = UTF-8 · Save as type = All Files
    • راضی نبودی؟ پرامپت ۲ با درخواست دقیق ← تکرار تا وقتی خوب شود
  • ۴دیتابیس را بساز
    • http://localhost/phpmyadmin ← تب Import ← database.sql ← Go
    • جدول messages باید ساخته شود
  • ۵فرم را به دیتابیس وصل کن
    • config.php — لوکال: کاربر root و رمز خالی
    • فرم تماس را پر کن و بفرست
    • inbox.php را باز کن — پیام باید آنجا باشد
      • خطا گرفتی؟ پرامپت ۳ + جدول خطاها
  • ۶منتشر کن — هاست داری؟
    • بله
      • Nameserver دامنه را به هاست وصل کن تا ۲۴ ساعت
      • فایل‌ها را در public_html آپلود و Extract کن
      • در cPanel دیتابیس و کاربر بساز ← .sql را Import کن
      • config.php را با اطلاعات هاست عوض کن
      • SSL را با Run AutoSSL فعال کن و Force HTTPS بزن
      • ✅ سایت روی دامنه‌ی خودت بالاست
    • نه
      • GitHub Pages یا Netlify فقط HTML/CSS/JS — بدون PHP
      • برای فرم: Formspree یا Google Forms
      • ✅ سایت رایگان آنلاین است
  • ۷کارت را در گالری کارگاه بفرست تا بقیه ببینند
  • ۸لینک سایت را در رزومه و لینکدین بگذار

اگر فقط ۳۰ دقیقه وقت دارید

  1. بسته‌ی فایل‌ها را دانلود کنید (دکمه 📦)
  2. پرامپت ۱ را با اطلاعات خودتان بفرستید
  3. کد را در index.html ذخیره کنید
  4. در Netlify پوشه را drag & drop کنید
  5. سایتتان آنلاین است
