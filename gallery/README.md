# گالری کارهای کارگاه

صفحه‌ای که شرکت‌کننده‌ها آخر کارگاه کدشان را در آن می‌گذارند، پیش‌نمایشش را همان‌جا
می‌بینند، و کار همه در یک گالری کنار هم نشان داده می‌شود.

خودش یک نمونه‌ی واقعی از همان چیزی است که در کارگاه درس دادید: فرم ← PDO ← دیتابیس ← نمایش.

## فایل‌ها

| فایل | کار |
|---|---|
| `index.php` | فرم ارسال با پیش‌نمایش زنده. لینک ویرایش هم به فرستنده می‌دهد. |
| `gallery.php` | همه‌ی کارها با پیش‌نمایش زنده + جست‌وجو |
| `view.php` | یک کار: پیش‌نمایش بزرگ + کدش |
| `admin.php` | پنل مدرس: تأیید، مخفی‌کردن، شاخص‌کردن، حذف، خروجی CSV |
| `config.php` | **تنها فایلی که باید ویرایش کنید** |
| `schema.sql` | جدول دیتابیس |
| `header.php` `footer.php` `style.css` | مشترک |

## راه‌اندازی — ۴ قدم

1. **دیتابیس:** در phpMyAdmin تب Import ← `schema.sql` ← Go
   (روی هاست: اول از cPanel → MySQL Databases یک دیتابیس و کاربر بسازید،
   بعد دو خط `CREATE DATABASE` و `USE` را از فایل حذف کنید و ایمپورت کنید.)

2. **`config.php` را باز کنید** و این چهار تا را تنظیم کنید:
   - `DB_NAME` / `DB_USER` / `DB_PASS`
   - `WORKSHOP_CODE` — کدی که سر کلاس می‌گویید. بدون آن کسی نمی‌تواند چیزی بفرستد.
   - `ADMIN_HASH` — رمز پنل مدیریت
   - `IP_SALT` — هر متن تصادفی

3. **رمز مدیریت را عوض کنید.** پیش‌فرض `admin1405` است:
   ```
   php -r "echo password_hash('رمز-جدید-شما', PASSWORD_DEFAULT);"
   ```
   خروجی را در `config.php` جایگزین `ADMIN_HASH` کنید.

4. **فایل‌ها را آپلود کنید** (مثلاً در `public_html/gallery/`) و لینک
   `https://yoursite.ir/gallery/` را به بچه‌ها بدهید.

## نکات

- **کد کارگاه** جلوی ارسال از بیرون کلاس را می‌گیرد. هر وقت خواستید عوضش کنید.
- **تأیید خودکار** پیش‌فرض روشن است تا سر کلاس کار بلافاصله دیده شود.
  اگر می‌خواهید اول خودتان ببینید، در `config.php` مقدار `AUTO_APPROVE` را
  `false` کنید؛ آن وقت کارها تا وقتی در پنل تأییدشان نکنید مخفی می‌مانند.
- **لینک ویرایش:** بعد از ارسال، به هر نفر یک لینک اختصاصی داده می‌شود تا
  بعداً کارش را به‌روز کند. به آن‌ها بگویید نگهش دارند.
- **اگر سایتشان چند فایل است**، بگویید از هوش مصنوعی بخواهند همه را در یک
  `index.html` ادغام کند. یا فقط آدرس سایت منتشرشده‌شان را بدهند.
- **خروجی CSV** در پنل مدیریت، فهرست شرکت‌کنندگان را برای صدور گواهی می‌دهد.

## امنیت

کد ارسالی هر نفر داخل `<iframe sandbox="allow-scripts">` و **بدون**
`allow-same-origin` اجرا می‌شود. یعنی مرورگر به آن یک مبدأ جداگانه می‌دهد و
جاوااسکریپت آن نمی‌تواند به صفحه‌ی گالری، به کوکی‌ها یا به کار بقیه دست بزند.
همه‌ی کوئری‌ها Prepared Statement‌اند و هر خروجی از `htmlspecialchars` رد می‌شود.

این برای یک گالری کلاسی کافی است. اگر خواستید لینک را عمومی منتشر کنید،
`AUTO_APPROVE` را خاموش کنید تا هر چیزی قبل از دیده شدن از نظر شما بگذرد.
