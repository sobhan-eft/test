# جعبه‌ابزار پرامپت‌های کارگاه طراحی سایت با هوش مصنوعی

> این فایل را باز نگه دارید و در حین کار، پرامپت‌ها را کپی کنید.
> جاهای داخل `[...]` را با اطلاعات خودتان جایگزین کنید.

---

## ۰) ساختار یک پرامپت خوب

هر پرامپت خوب پنج جزء دارد:

| جزء | یعنی چه | مثال |
|---|---|---|
| نقش | AI را در چه نقشی می‌خواهی | «تو یک طراح وب حرفه‌ای هستی...» |
| هدف | دقیقاً چه می‌سازی | «یک صفحه رزومه تک‌صفحه‌ای» |
| جزئیات | بخش‌ها، رنگ، محتوا | «شامل معرفی، پژوهش، تماس؛ رنگ آبی نفتی» |
| قالب خروجی | چطور تحویل بدهد | «کل کد در یک فایل، بدون توضیح اضافه» |
| محدودیت | چه چیزی نباشد | «بدون کتابخانه خارجی، راست‌چین، ریسپانسیو» |

---

## ۱) ساخت صفحه اصلی

```
تو یک طراح وب حرفه‌ای هستی که در ساخت سایت‌های فارسی و راست‌چین تخصص داری.

یک صفحه وب تک‌صفحه‌ای (Landing Page) شخصی برای من بساز با این مشخصات:

• نام: [نام و نام خانوادگی من]
• عنوان: دانشجوی پزشکی دانشگاه [نام دانشگاه]
• بخش‌ها به ترتیب: هدر با منوی چسبان، معرفی کوتاه با عکس، سوابق تحصیلی،
  فعالیت‌های پژوهشی، مهارت‌ها، فرم تماس، فوتر

الزامات فنی:
• کل کد در یک فایل index.html با CSS داخلی (بدون فایل جداگانه)
• کاملاً راست‌چین (dir="rtl") و با charset UTF-8
• فونت فارسی وزیرمتن از Google Fonts
• طراحی مدرن و تمیز با رنگ اصلی آبی نفتی و رنگ تأکیدی طلایی
• کاملاً ریسپانسیو (موبایل، تبلت، دسکتاپ)
• انیمیشن ملایم هنگام اسکرول
• بدون هیچ کتابخانه یا فریم‌ورک خارجی

خروجی: فقط کد کامل و آماده اجرا، بدون توضیح اضافه.
```

---

## ۲) اصلاح و تغییر (Iteration)

```
همان کد قبلی را نگه دار و فقط این تغییرات را اعمال کن:

۱. هدر هنگام اسکرول چسبان بماند و پس‌زمینه‌اش نیمه‌شفاف با افکت بلور شود
۲. در بخش معرفی، یک عکس دایره‌ای در سمت راست متن اضافه کن
۳. فاصله‌ی عمودی بین بخش‌ها را بیشتر کن تا صفحه نفس بکشد
۴. یک دکمه‌ی «دانلود رزومه» با رنگ طلایی زیر معرفی اضافه کن
۵. در موبایل، منو به شکل همبرگری جمع شود

کل فایل کامل و اصلاح‌شده را دوباره بده، نه فقط بخش تغییریافته.
```

> **مهم‌ترین جمله‌ی کل کارگاه:** همیشه بنویسید «کل فایل کامل را دوباره بده».

---

## ۳) ریسپانسیو کردن برای موبایل

```
این کد در موبایل به‌هم می‌ریزد. کل فایل را طوری بازنویسی کن که:
• در عرض‌های زیر ۷۶۸ پیکسل، ستون‌ها زیر هم بیایند
• اندازه‌ی فونت‌ها متناسب کوچک شود (از clamp استفاده کن)
• منو به دکمه‌ی همبرگری تبدیل شود
• هیچ اسکرول افقی ایجاد نشود
کل فایل کامل را بده.
```

## ۴) تغییر کامل ظاهر بدون دست زدن به محتوا

```
محتوا و ساختار HTML را دقیقاً حفظ کن و فقط بخش CSS را بازنویسی کن تا سایت
ظاهری مینیمال، روشن و آکادمیک پیدا کند: پس‌زمینه سفید، متن خاکستری تیره،
رنگ تأکیدی سرمه‌ای، گوشه‌های کمی گرد، سایه‌های خیلی ملایم.
کل فایل کامل را بده.
```

## ۵) حالت شب (دارک مود)

```
به این صفحه یک دکمه‌ی تغییر حالت روز/شب اضافه کن که:
• با CSS Variables پیاده شود
• انتخاب کاربر در localStorage ذخیره شود
• حالت پیش‌فرض از تنظیمات سیستم کاربر خوانده شود
کل فایل کامل را بده.
```

## ۶) بهینه‌سازی برای گوگل (SEO)

```
این صفحه را از نظر سئو بهینه کن: تگ title و meta description مناسب فارسی،
تگ‌های Open Graph برای اشتراک در شبکه‌های اجتماعی، ساختار درست هدینگ‌ها
(فقط یک h1)، متن alt برای همه‌ی تصاویر، و یک اسکیمای Person به صورت JSON-LD.
کل فایل کامل را بده.
```

## ۷) فرم تماس امن با PHP و MySQL

```
یک فرم تماس کامل و امن برایم بساز که شامل این فایل‌ها باشد:

۱. بخش HTML فرم (نام، ایمیل، موضوع، متن پیام) با ظاهری هماهنگ با سایت راست‌چین من
۲. فایل contact.php که اطلاعات فرم را در دیتابیس MySQL ذخیره کند
۳. دستور SQL ساخت جدول مربوطه

الزامات امنیتی (مهم):
• حتماً از PDO با Prepared Statement استفاده کن تا جلوی SQL Injection گرفته شود
• ورودی‌ها را اعتبارسنجی و پاک‌سازی کن (htmlspecialchars و filter_var)
• اطلاعات اتصال به دیتابیس را در یک فایل جداگانه config.php بگذار
• پیام موفقیت یا خطا را به شکل فارسی و کاربرپسند به کاربر نشان بده

هر فایل را جداگانه و کامل بده و بنویس هرکدام با چه نامی ذخیره شود.
```

## ۸) قالب گزارش خطا (مهم‌ترین پرامپت برای وقتی کار نمی‌کند)

```
این کد را تو برایم نوشتی ولی کار نمی‌کند.

۱) کدی که اجرا کردم:
[کد کامل را اینجا پیست کنید]

۲) خطایی که می‌بینم (عین متن):
[متن دقیق خطا را اینجا پیست کنید]

۳) چه انتظاری داشتم:
[مثلاً: انتظار داشتم پیام در دیتابیس ذخیره شود]

۴) چه اتفاقی واقعاً افتاد:
[مثلاً: صفحه سفید شد و هیچ چیزی ذخیره نشد]

محیط من: XAMPP روی ویندوز، PHP نسخه ۸.۲

لطفاً اول بگو دقیقاً مشکل از کجاست و چرا، بعد کل فایل اصلاح‌شده را بده.
```

## ۹) پرامپت‌های تکمیلی (بعد از کارگاه)

**اضافه کردن صفحه دوم:**
```
یک صفحه‌ی جدید به نام articles.html بساز که دقیقاً با همین استایل و همین هدر و فوتر
سایت من هماهنگ باشد و لیست مقالاتم را به شکل کارت نشان بدهد. لینکش را هم به منوی
اصلی در index.html اضافه کن. هر دو فایل کامل را بده.
```

**بهبود سرعت سایت:**
```
این صفحه را از نظر سرعت بهینه کن: بارگذاری تنبل تصاویر (lazy loading)،
کاهش حجم CSS، حذف کدهای بلااستفاده، و بارگذاری بهینه فونت.
کل فایل کامل را بده و در انتها فهرست تغییرات را بنویس.
```

**افزودن گوگل آنالیتیکس:**
```
کد Google Analytics 4 را با شناسه [G-XXXXXXX] در جای درست این صفحه قرار بده
و توضیح بده چرا آنجا گذاشتی. کل فایل کامل را بده.
```
