# کارگاه طراحی سایت با هوش مصنوعی — بسته‌ی ارائه

بسته‌ی کامل ارائه‌ی کارگاه دوساعته «طراحی سایت با هوش مصنوعی»
(مدرس: سبحان عفتی — شهریور ۱۴۰۵).

## محتویات

| فایل | توضیح |
|---|---|
| `index.html` | **دک ارائه.** فایل اصلی. با دابل‌کلیک در مرورگر باز می‌شود. |
| `starter-files/` | فایل‌های آماده‌ی سایت نمونه — پلن B اگر وسط کلاس اینترنت/AI در دسترس نبود. |
| `starter-files/prompts.md` | همه‌ی پرامپت‌های کارگاه، آماده‌ی کپی. |

## نحوه استفاده از دک ارائه

فایل `index.html` را در مرورگر باز کنید. هیچ نصبی لازم نیست.

### کلیدهای میان‌بر

| کلید | کار |
|---|---|
| `←` یا `Space` | اسلاید بعدی |
| `→` | اسلاید قبلی |
| `N` | نمایش/مخفی کردن **یادداشت مدرس** (متن دقیق چیزی که باید بگویید) |
| `G` | باز کردن **پلن اجرا** (چک‌لیست، زمان‌بندی، نقشه اضطراری) |
| `M` | فهرست اسلایدها |
| `T` | شروع/توقف تایمر — خودش می‌گوید عقب هستید یا جلو |
| `F` | تمام‌صفحه |

### امکانات

- **یادداشت مدرس:** روی هر اسلاید، متن پیشنهادی گفتار و نکات اجرایی.
- **تایمر هوشمند:** هر اسلاید یک «دقیقه‌ی هدف» دارد؛ تایمر مقایسه می‌کند و وضعیت
  «طبق برنامه / چند دقیقه عقب» را در نوار بالا نشان می‌دهد.
- **دکمه کپی:** همه‌ی پرامپت‌ها و کدها یک کلیک تا کلیپ‌بورد.
- **بخش‌های بازشونده:** توضیحات عمیق‌تر پشت دکمه، تا اسلاید شلوغ نشود.
- **خروجی PDF:** از فهرست → دکمه چاپ؛ همه‌ی اسلایدها با یادداشت‌ها چاپ می‌شوند.
- **حالت موبایل:** با کشیدن انگشت (swipe) بین اسلایدها حرکت کنید.

## استفاده از فایل‌های آماده (پلن B)

```
1. پوشه starter-files را در C:\xampp\htdocs\mysite کپی کنید
2. XAMPP را روشن کنید (Apache + MySQL)
3. در phpMyAdmin فایل database.sql را import کنید
4. مرورگر: http://localhost/mysite
```

برای فرم تماس، مقادیر داخل `config.php` را متناسب با محیط خود تنظیم کنید.
