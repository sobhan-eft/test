دامنه

🪧 دامنه: آدرس سایت شما

همان چیزی که کاربر در مرورگر تایپ می‌کند: sobhan-efati.ir

پسوند (TLD)

.com.ir.org.net.me.app

قیمت تقریبی سالانه

.ir حدود ۳۰ هزار تومان — ارزان‌ترین گزینه
.com حدود ۸۰۰ هزار تا ۱ میلیون تومان

از کجا بخریم؟

.ir از ایرنیک (nic.ir) یا نمایندگی‌ها
.com از هر ارائه‌دهنده معتبر

چطور یک نام دامنه‌ی خوب انتخاب کنم؟
  • کوتاه و قابل تلفظ: اگر نتوانید پای تلفن بگویید، نام بدی است.
  • بدون خط تیره و عدد تا جای ممکن (باعث اشتباه تایپی می‌شود).
  • نام خودتان عالی است برای رزومه علمی: name-family.ir
  • اول ثبت، بعد تبلیغ: قبل از چاپ روی کارت ویزیت، مطمئن شوید ثبت شده.
  • در ایرنیک می‌توانید آزاد بودن دامنه .ir را رایگان استعلام کنید.
دامنه‌ی رایگان هم داریم؟

بله، اما با محدودیت. اگر فعلاً نمی‌خواهید هزینه کنید، می‌توانید از زیردامنه‌های رایگان استفاده کنید:

username.github.ioyoursite.netlify.appyoursite.vercel.app

این‌ها برای نمونه‌کار و رزومه کاملاً کافی‌اند و در انتهای کارگاه به آن‌ها برمی‌گردیم. فقط توجه کنید: این‌ها PHP اجرا نمی‌کنند (فقط HTML/CSS/JS).

اینجا پرسش «چقدر هزینه دارد؟» حتماً می‌آید. خودت زودتر جوابش را بده تا اعتماد بسازی. «یه نکته‌ی مهم: دامنه‌ی .ir سالی حدود سی هزار تومنه. یعنی کمتر از یه فنجون قهوه. پس بهونه‌ی گرون بودن نداریم.» اگر وقت داری، زنده در nic.ir یک دامنه را استعلام کن — این «دیدن با چشم» خیلی مؤثرتر از توضیح است.

هاست ایرانی یا خارجی؟

هاست ایرانی: سرعت بالاتر برای کاربران داخل ایران، پشتیبانی فارسی، پرداخت ریالی ساده، و برای دامنه .ir طبیعی‌تر است. برای سایت شخصی و دانشگاهی گزینه‌ی منطقی است.

هاست خارجی: برای مخاطب بین‌المللی بهتر است، ولی پرداخت ارزی و گاهی محدودیت‌های دسترسی دارد.

پیشنهاد من برای شما: هاست ایرانی، لینوکس، cPanel، پلن اقتصادی با حداقل ۵۰۰ مگابایت فضا. همین کافی است.

موقع خرید هاست دنبال چه چیزهایی باشم؟
  • کنترل‌پنل cPanel (یا DirectAdmin) — نه پنل اختصاصی ناشناخته
  • پشتیبانی PHP نسخه ۸ به بالا و MySQL / MariaDB
  • SSL رایگان (Let's Encrypt) — نباید بابتش پول بگیرند
  • بکاپ‌گیری خودکار و گارانتی بازگشت وجه
  • پشتیبانی ۲۴ ساعته با تیکت — این را با یک تیکت تست کنید
هیچ برند خاصی را تبلیغ نکن. فقط معیار بده. اگر پرسیدند «کدوم شرکت؟» بگو معیارها را بگویم شما مقایسه کنید — این حرفه‌ای‌تر است و جای شبهه نمی‌گذارد. «من اسم هیچ شرکتی رو نمی‌برم، چون قرار نیست اینجا تبلیغ بشه. به‌جاش بهتون معیار می‌دم؛ با این معیارها خودتون بهترین رو انتخاب می‌کنین.»
DNS و SSL

🗺 DNS و 🔒 SSL — دو قطعه‌ی گمشده

🗺 DNS چیست؟

دفترچه تلفن اینترنت. کاربر می‌نویسد mysite.ir، DNS آن را ترجمه می‌کند به آدرس عددی سرور (مثل 185.4.x.x).

کار عملی شما فقط یک چیز است: Nameserver های هاست را در پنل دامنه وارد کنید.

🔒 SSL چیست؟

گواهی امنیتی که باعث می‌شود آدرس سایت با https و قفل سبز باز شود و اطلاعات کاربر رمزنگاری شود.

بدون آن، مرورگر به کاربر هشدار «Not Secure» می‌دهد و گوگل هم سایت را پایین‌تر نشان می‌دهد.

خبر خوب SSL امروز رایگان است. در cPanel بخشی به نام SSL/TLS Status یا Let's Encrypt هست؛ یک کلیک، و تمام.
نکته‌ای که همه را گیج می‌کند بعد از وارد کردن Nameserver، تا چند ساعت (گاهی تا ۲۴ ساعت) طول می‌کشد تا در کل اینترنت پخش شود. اگر سایتتان بلافاصله بالا نیامد، خراب نشده — فقط صبر کنید.
نکته‌ی «۲۴ ساعت صبر» را حتماً بگو، وگرنه فردا ۲۰ نفر پیام می‌دهند «سایتم بالا نیومد». «این یکی رو با خط قرمز یادداشت کنین: بعد از وصل کردن دامنه، ممکنه چند ساعت طول بکشه. اگه بلافاصله بالا نیومد، چیزی خراب نشده؛ فقط اینترنت داره خبردار می‌شه.»
cPanel

🎛 cPanel: داشبورد مدیریت سایت

cPanel رابط گرافیکی هاست است. یعنی به‌جای دستورهای پیچیده، با کلیک کار می‌کنید. این چند بخش را امروز لازم داریم:

📁 File Manager

مدیریت فایل‌های سایت. مهم‌ترین بخش برای ما. آپلود، حذف، ویرایش.

🗄 MySQL Databases

ساخت دیتابیس و کاربر دیتابیس برای بخش‌های پویای سایت.

🔐 SSL/TLS Status

فعال کردن گواهی امنیتی و https با یک کلیک.

🐘 Select PHP Version

انتخاب نسخه‌ی PHP. معمولاً ۸.۱ یا بالاتر انتخاب کنید.

📧 Email Accounts

ساخت ایمیل روی دامنه‌ی خودتان: info@yoursite.ir

🔎 phpMyAdmin

مشاهده و ویرایش جدول‌های دیتابیس به صورت گرافیکی.

قانون طلایی فایل‌های سایت شما حتماً باید داخل پوشه‌ای به نام public_html قرار بگیرند. هرچیزی بیرون این پوشه، از اینترنت دیده نمی‌شود.
اگر به cPanel دسترسی زنده داری، همین‌جا اشتراک صفحه بگذار و یک تور ۲ دقیقه‌ای بده. دیدن محیط واقعی، ترس را می‌ریزد. «این محیط شاید اولش شلوغ به‌نظر برسه، ولی ما فقط با شیش تا از این آیکون‌ها کار داریم. بقیه‌ش رو می‌تونین فعلاً نادیده بگیرین.» اگر دسترسی نداری، از پلن B استفاده کن: اسکرین‌شات‌های از پیش آماده. هرگز وسط کلاس دنبال دسترسی نگرد.

  3. اجرای Control Panel: بعد از نصب، پنل کنترل XAMPP را باز کنید.
  4. روشن کردن سرویس‌ها: روبه‌روی Apache و MySQL دکمه Start را بزنید. هر دو باید سبز شوند.
  5. تست: در مرورگر آدرس http://localhost را باز کنید. اگر صفحه‌ی خوش‌آمد XAMPP آمد، تمام است. ✅
شایع‌ترین خطا: Apache روشن نمی‌شود (Port 80 in use) معمولاً اسکایپ، IIS یا یک برنامه دیگر پورت ۸۰ را گرفته. راه‌حل سریع: در XAMPP روی Config → httpd.conf بزنید، عدد Listen 80 را به Listen 8080 تغییر دهید و سپس سایت را با http://localhost:8080 باز کنید.

فرم تماس واقعی با PHP و MySQL

تا اینجا سایت ما ایستا بود. حالا کاری می‌کنیم که پیام‌های کاربران واقعاً ذخیره شوند.

اتصال دامنه به هاست

  1. هاست را بخرید. بعد از خرید، ایمیلی دریافت می‌کنید که شامل آدرس cPanel، نام کاربری، رمز و دو Nameserver است. مثل: ns1.hostname.com و ns2.hostname.com
  2. وارد پنل دامنه شوید. جایی که دامنه را ثبت کرده‌اید (مثلاً ایرنیک برای .ir).
  3. بخش DNS / Nameserver را پیدا کنید و دو Nameserver هاست را جایگزین مقادیر فعلی کنید و ذخیره کنید.
  4. صبر کنید. از چند دقیقه تا ۲۴ ساعت. در این فاصله می‌توانید با آدرس موقت هاست کار کنید.
آدرس موقت اکثر هاست‌ها یک آدرس موقت می‌دهند (مثل username.hostname.com) تا قبل از اتصال دامنه هم بتوانید سایتتان را ببینید و تست کنید.
اشتباه رایج Nameserver را در پنل هاست عوض نکنید! باید در پنل دامنه عوض شود. این دو جای متفاوت‌اند.
این بخش خشک است — سریع رد شو و بگو در ضبط جلسه دوباره ببینند. تمرکز را روی مرحله بعد (آپلود) بگذار که ملموس‌تر است.

📁 آپلود فایل‌ها با File Manager

  1. فایل‌های سایتتان را zip کنید. (نکته: خود فایل‌ها را انتخاب و zip کنید، نه پوشه‌ی بیرونی را)
  2. وارد cPanel شوید → روی File Manager کلیک کنید.
  3. وارد پوشه‌ی public_html شوید. این مهم‌ترین قدم است.
  4. روی Upload بزنید و فایل zip را بکشید و رها کنید.
  5. برگردید به File Manager، روی فایل zip راست‌کلیک کنید و Extract بزنید.
  6. فایل zip را حذف کنید. مطمئن شوید index.html مستقیماً داخل public_html است.
  7. دامنه‌تان را در مرورگر باز کنید. 🎉
شایع‌ترین اشتباه کل این مرحله اگر ساختار شما این‌طور شد: public_html/mysite/index.html ← سایت شما در آدرس yoursite.ir باز نمی‌شود، بلکه در yoursite.ir/mysite باز می‌شود.
ساختار درست: public_html/index.html
این یک اشتباه است که همه بار اول مرتکب می‌شوند. آن را عمداً جلوی کلاس مرتکب شو و بعد درستش کن. یادگیری از اشتباه دیده‌شده چند برابر است. «ببینین من الان عمداً یه اشتباه می‌کنم که شما بعداً نکنین...»

دیتابیس و فعال‌سازی SSL

🗄 انتقال دیتابیس

  1. در لوکال phpMyAdmin → دیتابیس → تب Export → Go (فایل .sql دانلود می‌شود)
  2. در cPanel → MySQL Databases → یک دیتابیس و یک کاربر بسازید و کاربر را با دسترسی کامل به دیتابیس وصل کنید
  3. در cPanel → phpMyAdmin → دیتابیس جدید → تب Import → فایل .sql را آپلود کنید
  4. در فایل config.php نام دیتابیس، کاربر و رمز را به مقادیر هاست تغییر دهید

🔒 فعال‌سازی SSL

  1. در cPanel → SSL/TLS Status
  2. دامنه را انتخاب کنید → Run AutoSSL
  3. چند دقیقه صبر کنید تا تیک سبز بیاید
  4. در بخش Domains، گزینه‌ی Force HTTPS Redirect را روشن کنید
  5. سایت را با https:// باز کنید و قفل را ببینید ✅
نکته‌ی حیاتی درباره config.php اطلاعات دیتابیس در لوکال‌هاست معمولاً کاربر root با رمز خالی است. روی هاست واقعی حتماً متفاوت است. اگر بعد از آپلود خطای اتصال به دیتابیس گرفتید، ۹۹٪ مشکل همین است.
اگر وقت تنگ است، این اسلاید را فقط مرور کن و بگو جزئیاتش در فایل ارائه و ضبط جلسه هست. تمرکزت را نگه دار برای اسلاید رفع خطا و جمع‌بندی.

    ۵) هفت اصل ارائه‌ی خوب

    • نشان بده، بعد توضیح بده. اول خروجی را ببینند، بعد بفهمند چطور ساخته شد.

    • هر بخش را با یک جمله جمع کن قبل از رفتن به بخش بعد.
    • محدودیت‌ها را هم بگو. مدرسی که فقط تعریف می‌کند، فروشنده به‌نظر می‌رسد.
